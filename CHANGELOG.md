# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-10-17

### Added

- Chrome MV3 extension for keeping local reading notes on X profile timelines.
- Saves publication time, post text, links, media URLs, and post URL.
- Local deduplication and storage in `chrome.storage.local`.
- Page-by-page assisted reading mode with a manual stop control.
- Live total and session counters on the X page and in the extension popup.
- JSONL and CSV export.
- Clear current-profile or all-notes controls.
