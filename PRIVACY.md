# Privacy Policy

X Timeline Notebook is a local-only Chrome extension. It does not contain
analytics, advertising, account systems, or remote servers.

## What is stored

When you read an X profile page, the extension stores the following information
in your browser's local extension storage:

- Post publication time
- Post text
- Links and media URLs shown with the post
- Post URL and status ID
- Author handle and display name
- Page URL and save timestamp

## Where data is stored

All data is stored locally in `chrome.storage.local`. It is not uploaded by
this extension.

## Exports

Exports are created only when you explicitly click an export button. Exported
JSONL/CSV files are saved through Chrome's download system to your computer.

## Third-party access

The extension runs only on `x.com` and `twitter.com`. X itself may apply its
own logging, limits, and policies when you use its website.

## Your control

You can clear the current profile’s notes or all notes from the extension
popup at any time. You may also remove the extension, which removes its local
storage.
